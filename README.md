# Number Guessing Game

This repository contains two implementations of a number guessing game written in different languages.

## C Version
- Fixed range (1–100)
- Maximum of 10 attempts
- Replay functionality
- Demonstrates procedural programming and use of `rand()`

## Python Version
- User-defined difficulty level
- Unlimited guesses
- Robust input validation using `try/except`
- Demonstrates Pythonic error handling

The goal of this project is to compare how similar logic is implemented across languages with different design choices.
